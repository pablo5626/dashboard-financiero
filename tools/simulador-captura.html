Simulador de captura automática

Cada teléfono manda al endpoint real el mismo JSON que mandaría el dispositivo. Lo que llega aparece en la app en Gastos → "Capturas por revisar".

Abriste el archivo directo desde la carpeta. Así el navegador bloquea el envío a Supabase y no guarda el token. Ábrelo desde el servidor de desarrollo (con npm run dev corriendo): http://localhost:5173/dashboard-financiero/tools/simulador-captura.html
